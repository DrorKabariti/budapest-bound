# Budapest Bound 2.0 — PWA

אפליקציית טיול בעברית ל-17–21.11.2026. React + Vite + vite-plugin-pwa.

## הפעלה

```bash
npm install
npm run dev
```

## בדיקת גרסת ייצור

```bash
npm run build
npm run preview
```

## פריסה ל-Vercel

1. העלה את תיקיית הפרויקט לריפו ב-GitHub.
2. ב-Vercel בחר Add New Project וחבר את הריפו.
3. Framework Preset: Vite; Build Command: `npm run build`; Output Directory: `dist`.
4. פרוס ב-HTTPS, פתח בטלפון והוסף למסך הבית.

## עבודה אופליין

ה-Service Worker שומר את קובצי האפליקציה אחרי ביקור ראשון ברשת. תוכן המסלולים מוטמע באפליקציה; בחירות ונתונים אחרונים נשמרים ב-localStorage. התחזית ושער המטבע מתעדכנים דרך APIs ציבוריים בעת חיבור לרשת, וניתנים לצפייה מהעותק האחרון שנשמר במצב אופליין. מפות Google, ניווט חי, אתרים חיצוניים והזמנות **לא** זמינים אופליין; להורדת מפה יש להשתמש באפליקציית Google Maps בנפרד. הכפתור 'הכן לאופליין' מבקש לעדכן את Service Worker, אך אינו מוריד מפות חיצוניות.

## מקורות נתונים

- מזג אוויר: Open-Meteo, תחזית עד 7 ימים קדימה; תאריכי הטיול יהיו זמינים רק סמוך למועד.
- שער HUF/ILS: open.er-api.com, שער ייחוס שאינו כולל עמלות.

## חשוב

לא בוצע אימות בזמן אמת של שעות פתיחה, מועדי שווקי חג המולד, הזמנות אטרקציות או לוחות תחבורה. בדוק לפני הגעה. קישורי ניווט מבוססים על חיפוש שם המקום ב-Google Maps ולא על מסלול שנבדק. אין צורך בשרת ייעודי או במפתחות API למימוש הבסיסי.
